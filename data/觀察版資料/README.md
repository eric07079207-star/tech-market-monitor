# 觀察版資料

產生時間 UTC：2026-05-23T07:58:13+00:00

這個資料夾是給人工檢查、研究與未來資料倉儲使用的觀察版匯出。

- `data/cache/` 是系統與 Streamlit 使用的正式快取，請保留不動。
- `data/觀察版資料/` 是由快取複製與轉出的檢查版資料。
- `.csv` 方便用 Excel、Numbers 或一般文字工具查看。
- `.parquet` 保留原本高效率格式，方便未來做回測與資料倉儲。
- `資料清單.csv` 會列出來源檔案、筆數、最新資料日期、最近抓取時間與檔案大小。

## 資料分類

### 01_市場價格
- 市場價格：股票、ETF、年度十大與市場壓力標的的日線價格與量能。

### 02_總經與市場壓力
- 總經市場壓力：FRED 總經、利率、信用利差與市場壓力資料。

### 03_標的新聞
- 標的新聞：科技股、ETF 與 watchlist 相關新聞。

### 04_國際新聞
- 國際新聞：國際重大新聞、戰爭、貿易、央行與能源消息。
- TSLA專題新聞：TSLA 專用關鍵字追蹤新聞與分類結果。

### 05_潛力股探索
- 探索新聞：隨機市場主題新聞，用來尋找潛在個股。
- 探索股票提及：從探索新聞中擷取出的股票代號與新聞來源。

### 06_候選股追蹤
- 每日候選股：每日量化後的候選觀察股名單。
- 候選股歷史：每日 Top 15 候選觀察股歷史紀錄。
- 候選股表現驗證：候選股入榜後的後續表現驗證資料。

### 07_預測驗證
- 市場預測紀錄：市場判斷與後續 5D/20D/60D 驗證紀錄。

### 08_AI摘要
- AI市場摘要：每日 AI 或規則摘要結果。
- AI摘要歷史：每日 AI 或規則摘要歷史，用於回看與後續準確率驗證。

### 09_金融知識圖譜
- 事實層：客觀事件與來源資料。
- 敘事層：量化敘事與情緒特徵。
- 反應層：事件後市場反應與驗證結果。
- 事件連結：事件與標的關聯關係。
- 知識圖譜資訊：金融知識圖譜更新時間與筆數。

### 11_資料治理
- 資料治理摘要：新聞資料流 official、pending 與 rejected 分層統計。

### 10_LSTM模型
- LSTM特徵表：LSTM 訓練與回測使用的序列特徵表。
- LSTM切分表：LSTM 訓練/驗證/測試切分。
- LSTM最新預測：LSTM 每次更新產生的最新預測結果。
- LSTM回測：LSTM 歷史回測與驗證紀錄。
- LSTM模型權重：LSTM 訓練後輸出的模型權重。
- LSTM模型資訊：LSTM 模型版本、訓練指標與 metadata。
- LSTM標準化器：LSTM 特徵標準化參數。
- LSTM流程狀態：LSTM 更新狀態、最後訓練時間與工件統計。

### 00_資料說明
- 快取更新資訊：目前快取更新時間、資料起始日與資料筆數。

## 使用方式

每次要重新整理觀察版資料時，執行：

```bash
python scripts/export_observation_data.py
```

資料清單請看：`00_資料說明/資料清單.csv`
