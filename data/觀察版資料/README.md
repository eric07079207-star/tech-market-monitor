# 觀察版資料

產生時間 UTC：2026-08-23T23:22:44+00:00

這個資料夾是給人工檢查、研究與未來資料倉儲使用的觀察版匯出。

- `data/cache/` 是系統與 Streamlit 使用的正式快取，請保留不動。
- `data/觀察版資料/` 是由快取複製與轉出的檢查版資料。
- `.csv` 方便用 Excel、Numbers 或一般文字工具查看。
- `.parquet` 保留原本高效率格式，方便未來做回測與資料倉儲。
- `資料清單.csv` 會列出來源檔案、筆數、最新資料日期、最近抓取時間與檔案大小。

## 資料分類

### 01_市場價格
- 市場價格：股票、ETF、年度十大與市場壓力標的的日線價格與量能。

### 02_總經與市場壓力
- 總經市場壓力：FRED 總經、利率、信用利差與市場壓力資料。
- SEC基本面觀測：以 SEC filing date 保存的公司基本面原始觀測，供 point-in-time 歷史研究使用。

### 03_標的新聞
- 標的新聞：科技股、ETF 與 watchlist 相關新聞。

### 04_國際新聞
- 國際新聞：國際重大新聞、戰爭、貿易、央行與能源消息。
- TSLA專題新聞：TSLA 專用關鍵字追蹤新聞與分類結果。

### 05_潛力股探索
- 探索新聞：隨機市場主題新聞，用來尋找潛在個股。
- 探索股票提及：從探索新聞中擷取出的股票代號與新聞來源。

### 06_候選股追蹤
- 每日候選股：每日量化後的候選觀察股名單。
- 候選股歷史：每日 Top 15 候選觀察股歷史紀錄。
- 候選股表現驗證：候選股入榜後的後續表現驗證資料。

### 07_預測驗證
- 市場預測紀錄：市場判斷與後續 5D/20D/60D 驗證紀錄。
- 分層歷史市場樣本：固定 seed 的分層隨機歷史市場樣本；標示技術/市場可用性與 KG、基本面歷史覆蓋缺口。
- 因子有效性報告：技術與市場壓力因子依歷史分層樣本計算的後續報酬與回撤；不宣稱因果關係。

### 08_AI摘要
- AI市場摘要：每日 AI 或規則摘要結果。
- AI摘要歷史：每日 AI 或規則摘要歷史，用於回看與後續準確率驗證。

### 09_金融知識圖譜
- 事實層：客觀事件與來源資料。
- 敘事層：量化敘事與情緒特徵。
- 反應層：事件後市場反應與驗證結果。
- 事件連結：事件與標的關聯關係。
- KG研究觀察預測：每日以知識圖譜事件與敘事建立的 QQQ 1D/5D/20D 研究觀察及後續驗證。
- KG研究觀察預測V2：多因子趨勢預測、實際報酬、回撤、基準訊號與信心校準紀錄。
- KG歷史回測準備度：逐樣本標示歷史多來源事件與 point-in-time 基本面的可用性，防止缺資料的回測被誤讀。
- 知識圖譜資訊：金融知識圖譜更新時間與筆數。

### 11_資料治理
- 資料治理摘要：新聞資料流 official、pending 與 rejected 分層統計。
- 更新執行紀錄：每次更新流程的整體結果與成功/失敗統計。
- 更新模組紀錄：每個更新模組的 success、fallback 或 failed 狀態與原因。

### 12_市場情緒
- 市場情緒層：VIX、信用利差、相對強弱與新聞情緒的日度特徵。
- 大盤事件窗：VOO/QQQ 在 20 個交易日內波動超過 10% 的歷史事件樣本。

### 10_LSTM模型
- LSTM訓練特徵表：需要未來報酬標籤的 LSTM 訓練與回測序列特徵。
- LSTM日常監控特徵表：不等待未來報酬標籤的每日即時推論特徵。
- LSTM切分表：LSTM 訓練/驗證/測試切分。
- LSTM最新預測：LSTM 每次更新產生的最新預測結果。
- LSTM回測：LSTM 歷史回測與驗證紀錄。
- LSTM模型權重：LSTM 訓練後輸出的模型權重。
- LSTM模型資訊：LSTM 模型版本、訓練指標與 metadata。
- LSTM標準化器：LSTM 特徵標準化參數。
- LSTM流程狀態：LSTM 更新狀態、最後訓練時間與工件統計。
- LSTM預測品質評估：LSTM 基準比較、分類指標、報酬統計與資料洩漏檢查。

### 00_資料說明
- 快取更新資訊：目前快取更新時間、資料起始日與資料筆數。

### 13_專案記憶
- 專案長期記憶：長期有效的目標、規則、架構與已確認原則。
- 討論摘要：重要討論主題、結論與執行狀態。
- 當前上下文：目前版本重點、已知風險與下一步。
- 決策登錄：已確認決策的結構化記錄。
- 記憶更新紀錄：專案記憶何時被更新、為什麼更新。
- Word 摘要：提供人工檢查用的可讀版本。

## 使用方式

每次要重新整理觀察版資料時，執行：

```bash
python scripts/export_observation_data.py
```

資料清單請看：`00_資料說明/資料清單.csv`
