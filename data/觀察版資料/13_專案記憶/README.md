# 專案記憶

這個資料夾用來保存專案長期記憶、重要討論摘要與決策紀錄，目的是避免聊天壓縮後遺失關鍵上下文。

## 檔案說明

- `project_memory.md`：長期有效的專案事實、原則、規則與已確認架構。
- `conversation_log.md`：重要討論主題、最後結論、目前狀態與關聯檔案。
- `active_context.md`：當前版本、最近更新、已知風險、下一步與等待確認事項。
- `decision_register.csv`：已確認決策的結構化登錄。
- `memory_changelog.csv`：記憶內容何時、為什麼被更新。
- `專案記憶與討論摘要.docx`：給人工檢查的可讀版摘要。
- `archive/`：歷史版本或後續延伸輸出保留區。

## 更新原則

- 只記錄長期有效、已確認、可回溯的內容。
- 不保存 API key、密碼、token、貼上的敏感字串。
- 討論中但未確認的想法只放在 `conversation_log.md` 或 `active_context.md`，不直接當成既定規則。
- 大型功能完成、架構改動、資料來源調整、例行檢查發現長期風險時，應同步更新這裡。

## 查看方式

- Streamlit 的「專案記憶」頁籤會直接讀這裡。
- Word 檔主要給你快速查看與人工驗證。
- Markdown 與 CSV 是主要來源，Word 是可讀匯出版本。
